# GC Universal Timer

头马通用计时器（各俱乐部通用），由 Global Communicators Toastmasters Club（GC）大脑项目组（GC Brain）持续改进。

- **作者署名**：GC Brain
- **原版在线体验**：<https://gctoastmaster.club/universal-timer.html>
- **开源许可**：[MIT License](LICENSE)

这是一个纯 HTML、CSS、JavaScript 的单文件工具：无需安装、无需后端、无第三方库或 CDN 依赖，主要功能可离线使用。

## 功能

- 备稿演讲、即兴演讲、点评和自定义角色预设；
- 绿、黄、红时间阈值可手动调整；
- 1–7 分钟快速计时，以及 0.5–180 分钟自定义计时；
- 与个人计时并行的环节总倒计时，支持暂停、终止和超时读数；
- 全屏三色灯和到点提示音；
- 本场演讲记录、合格状态与合格率统计；
- 生成中英双语 Timer's Report，可复制或下载 TXT；
- 刷新后恢复本地记录和环节计时；
- 桌面端与手机端自适应布局。

## 使用

1. 下载 `universal-timer.html`。
2. 使用当前版本的 Chrome、Edge 或其他现代浏览器打开。
3. 选择角色预设或设定自定义时间，输入演讲者姓名，点击“开始”。

键盘快捷键：

- `空格`：开始或暂停；
- `L`：记录并进入下一位；
- `R`：重置个人计时；
- `F`：进入全屏三色灯；
- `Esc`：退出全屏。

## 数据与隐私

本工具不包含后端、第三方统计脚本或自动外部数据请求。会议名称、演讲者姓名和计时记录仅保存在当前浏览器的 `localStorage` 中，不会由本代码自动上传，也不会跨设备同步。

清理浏览器站点数据可能删除这些记录。不同浏览器对 `file://` 页面的本地存储策略可能不同，正式会议建议使用稳定的浏览器和打开方式。

本项目是通用纯前端版，不是带当期议程和云端同步功能的 `gc-timer-mobile` 版本。
